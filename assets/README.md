# Portfolio Assets Directory

This directory is reserved for static assets such as project images, custom audio tracks, and graphics.

Currently:
- **UI Sound Effects**: Synthesized dynamically at runtime using the browser's Web Audio API in [main.js](file:///Users/safasuhrawardy/personal-portfolio/js/main.js) (no `.mp3` files needed).
- **Lofi Synth Tracks**: Generated procedurally in [widgets.js](file:///Users/safasuhrawardy/personal-portfolio/js/widgets.js) or streamed from public domain CDNs.
- **Developer Avatar**: Drawn dynamically via a vector base64 SVG generator in [main.js](file:///Users/safasuhrawardy/personal-portfolio/js/main.js).
- **Project Images**: Linked directly from premium public stock photography references in [data.js](file:///Users/safasuhrawardy/personal-portfolio/js/data.js).
